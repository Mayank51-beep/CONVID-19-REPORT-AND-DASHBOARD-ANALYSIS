# CONVID-19-REPORT-AND-DASHBOARD-ANALYSIS

📌 Project Overview

An interactive Power BI dashboard analyzing India's COVID-19 trends, vaccination progress, and near-term case forecasts. This project transforms historical data into meaningful visual insights through time-series analysis, KPIs, and forecasting.

📊 Dashboard Highlights
  Core KPIs: Total reported cases, latest 7-day average, and cumulative vaccination doses.
  Time-Series Analysis: Daily new cases, rolling averages, monthly trends, and MoM percentage changes.
  30-Day Forecast: Explore projected case trends with forecast uncertainty.
  Interactive Visuals: Dynamic charts, filters, and an intuitive dashboard layout.
  Key Insights: Highlights major COVID-19 waves, trend changes, vaccination progress, and forecast limitations.

🛠️ Tools & Skills

Power BI · DAX · Power Query · Data Visualization · Time-Series Forecasting · Data Analysis

🎯 Project Objective

To demonstrate how data analytics and interactive visualization can uncover meaningful patterns in public health data and support data-driven understanding.
